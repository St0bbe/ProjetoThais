# Projeto Thais — Thais Studio

Protótipo responsivo de criação e edição de vídeos, pensado para funcionar no navegador do celular.

## Recursos atuais
- Upload de vídeo local
- Preview responsivo
- Formatos 9:16, 1:1 e 16:9
- Play/pause, áudio, ajuste de enquadramento e velocidade
- Campos de título, roteiro e estilo
- Interface mobile-first

## Teste local
Abra o arquivo `index.html` no navegador.

## Publicação
O projeto é compatível com GitHub Pages por ser estático.
